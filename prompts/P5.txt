P5 交易决策工具（Trading Decision Engine）：用 Elder 三重滤网 + 风控法则给出「拿来就能用」的买卖判断，不是做展示看板。

====================================================================
【产品定位 — 用户已拍板，不要再问、不要做方案对比、不要重做一张图】
====================================================================

- 用户原话：「用书本作者的思路以及他的判断买卖点，而不是花这么多时间只做出一张图出来。我们要拿来运用不是做展示」。
- 用户在本轮选择题中**只选了「买卖判断 + 交易计划」**：
  **输入任意股票代码 → 直接给出「现在该买 / 该卖 / 观望」的结论 + 完整交易计划
  （入场价、止损价、目标价、按 2%/6% 法则算出的仓位股数）+ 每一条判断的依据链。**
- 用户**没有**选择「历史回测验证」「每日选股清单」「持仓与交易日志」——本阶段一律不做，
  不要擅自扩大范围。历史信号只用于规则自检，不作为主输出。
- K 线图 / 指标 / 买卖箭头**降级为辅助视图**：用来核对判断，不是产品主体。
  布局上「决策卡片」必须在首屏最上方，图在下方。不要把工时花在美化图表上。
- 判定范围：沪深 A 股，仅做多（A 股无做空，空头方向一律输出「观望」）；T+1；100 股整手。
- 风格沿用现有 triple-screen.html（用户认可），不重画、不改配色。

====================================================================
【与前几阶段的本质区别 — 最重要，先读懂再动手】
====================================================================

- P3/P4 做的是「历史回测结果展示」：把算好的 120 条历史信号画在图上，是**过去时**。
- P5 要的是「**对最新一根已收盘 K 线给出当前决策**」：用户打开 → 输入代码 →
  立刻看到「今天这只票该不该买、什么价位买、买多少股、止损放哪、为什么」，
  是**现在时、可执行**。若做成又一张标注图，本阶段视为失败。

====================================================================
【核心交付 D1~D6 — 缺一项视为未完成】
====================================================================

D1 任意代码实时查询
- 页面顶部：股票代码输入框 + 「查询」按钮（回车可触发）。
- 格式兼容：600519、600519.SH、sh600519、SZ000001、000001。
- 解析：6/9 开头→沪 sh（含 688）、0/2/3 开头→深 sz（300 创业板）；5 开头→沪 ETF（顺带支持）。
- 成功则加载该股日线 + 周线并刷新全部区块；标题、股票名称动态更新。
- 失败（代码不存在 / 网络错误 / 限流）：**中文错误提示 + 重试按钮**，禁止白屏或英文报错。

D2 三重滤网「当前判断」（严格按 Elder，沿用已拍板规格）
- 数据：日线（前复权）+ 周线（前复权）；第 3 重用日线 T-1 高低点（见 D6 降级说明）。
- **第 1 重（周线，硬开关）**：EMA13 斜率 > 0 且 MACD 柱(12,26,9) 最近两根斜率 > 0
  → 允许做多；否则方向 = 禁止买入 / 观望。A 股无做空，空头方向一律「观望（不做空）」。
  ⚠️ 这一重是严格开关：不满足时**绝对不能**产生任何买入结论（与现有 signals.py 的 direction 逻辑一致）。
- **第 2 重（日线，找逆势回调）**：沿用 P4 已拍板的 **SYS-04 简化规格**——
  Elder-Ray / Stochastic K / RSI 任一成立即 setup（RSI14、Stoch 13/3、阈值 30/70）。
  **不要重新讨论、不要改动这个已拍板的简化**。Force Index 2 日 EMA 仅作参考项展示，
  不参与强制判定。
- **第 3 重（入场触发）**：buy stop = T-1 已收盘日线 high + tick（tick=0.01）；
  最新日线 high 已穿越 → 状态「已触发 / 可挂单」，否则「等待触发价 XXX」。
  跳空按 open 记候选成交价。
- 输出**三态结论**：`BUY`（含触发状态）/ `SELL`（仅针对已有持仓的平仓、保护止损提示）/
  `WAIT 观望`，并用中文写明**卡在哪一重**（如「第 1 重周线方向未确认，禁止买入」、
  「第 2 重未出现回调 setup，等待」）。

D3 交易计划卡片（「拿来运用」的关键，必须可算、可核对）
- 用户输入：账户权益（默认 100000）+ 可选「当月已用风险额度」。
- **2% 法则**：最大风险额 = 权益 × 2%；每股风险 = 入场价 − 初始止损；
  股数 = floor(最大风险额 / 每股风险)，**向下取整到 100 股整手**；
  显示股数、金额、占总权益比例。
- **初始止损**：按日线结构给价（T-1 low − tick 或现有 risk.py 口径），标注「保护性止损」；
  若止损距离过大导致股数为 0 → 明确提示「风险过大，不建议开仓」。
- **50% 法则**：给出动态规则说明——浮盈后止损上移至
  `entry + 0.50 × (best_price − entry)`（`profit_protect_ratio=0.50`，D11 已拍板保持不变）。
- **6% 法则**：结合输入的当月已用额度，输出「本月是否还能开新仓」；
  口径沿用 P4 已拍板的 `monthly_halt`（账户权益回撤 6%），注明第 2 版口径差异（D8 已决策维持）。
- **目标价**：按 Elder「用长期图表设止盈」给一个参考结构位并注明「参考、需人工判断」；
  **不得伪造精确公式或承诺收益**。
- 固定显示：「仅供研究与回测，不构成投资建议」。

D4 依据链（每个判断节点可展开）
- 第 1 重方向、第 2 重 setup、第 3 重触发、2%/6% 仓位，均能展开看到：
  `rule_id` + 参与计算的指标数值 + `source_url` / `source_quote` / `confidence` +
  书内确认（《以交易为生》原书第 2 版页码，取自 `docs/indicators.yaml` 的 `book_*` 字段）。
- 前端内嵌一份精简 specs JSON（只含展示字段）；**不得伪造任何书内定位**。

D5 历史规则自检（证明逻辑可用，不是画出来好看）
- 对该股近 250 个交易日回放同一套三重滤网规则，输出：信号次数、BUY/SELL 分布、
  按「次日开盘买入、持有 N 日」口径的胜率与平均收益、最大回撤。
- 口径必须写明；**不得宣称策略盈利、不得美化数字**。此段仅用于自检。

D6 边界与降级
- 数据不足（周线 < 35 根 / 日线 < 60 根）→「数据不足，无法判断」，不给结论。
- 停牌 / 触及涨跌停 / ST → 中文标注「可能无法成交 / 不参与」。
- 60 分钟线接口不可用 → 第 3 重降级为日线 T-1，页面注明「日内触发为日线近似」。
- 连续查询防抖；接口失败自动重试 1 次，仍失败则中文错误提示。
