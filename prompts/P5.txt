P5 查询版看板（Query Dashboard）：从「单票回测展示」升级为「任意代码股票查询工具」。

====================================================================
【产品定位 — 用户已确认，不要重新讨论、不要再出方案对比】
====================================================================

- 用户原话要点：这不是「一只票的回测结果展示页」，也不是「与市场对接的实盘交易软件」；
  它是一个「随意放一个股票代码进去就能查询这只票」的**查询/分析工具**。
- 指标与买卖点思路沿用 Elder（三重滤网）；**整体画面风格沿用现有 triple-screen.html，
  用户已明确认可，不要推翻重画、不要改配色风格**。
- 本阶段允许改 presentation/ 与新增前端文件；指标计算在浏览器端用 JS 重新实现是允许的；
  **不改 elder_indicators/、market_data/、strategy_adapters/、tests/ 的任何代码**。

====================================================================
【用户反馈清单 — 逐条落实，交付时逐条自查，缺一条视为未完成】
====================================================================

F1 任意代码查询（本轮核心）
- 页面顶部显著位置：股票代码输入框 + 「查询」按钮（支持回车触发）。
- 输入格式兼容：600519、600519.SH、sh600519、SZ000001、000001 等常见写法。
- 解析规则：6/9 开头→沪 sh（含 688 科创板）、0/2/3 开头→深 sz（300 创业板）；
  5 开头→沪场内基金/ETF（顺带支持即可，不作为验收项）。
- 查询成功：加载该股日线并渲染全部区块（快照条、K线、副图、买卖点、依据面板）；
  页面 <title>、快照条跟随股票名称与代码动态更新。
- 查询失败（代码不存在、网络错误、接口限流）：界面给出**中文错误提示**与重试按钮，
  禁止白屏或英文报错。

F2 主图指标下拉菜单（仿专业行情软件）
- K 线主图提供指标模式下拉：**MA / EMA / BOLL / 不显示**（至少这四项）。
- 各模式默认参数：MA(5,10,20,60)、EMA(13,26)、BOLL(20,2)；**每条线的周期允许在界面修改**。
- 切换后立即重绘，不影响 K 线本身与买卖点箭头。

F3 每条线写明是什么指标（图例）
- 主图每条叠加线必须显示「指标名 + 参数 + 当前值」图例，例如：
  「MA 5: 1452.30」「MA 10: 1448.11」「EMA 13: 1311.94」
  「BOLL(20,2) 上轨 1502.5 / 中轨 1471.2 / 下轨 1440.1」。
- 副图标题同样写明参数：「MACD(12,26,9)」「RSI(14)」「随机 K(13,3) 30-70」。
- 图例随十字光标所在日期动态更新当前值（参考现有 EMA13 图例的交互方式）。

F4 中文本地化（用户圈出的硬性问题）
- 时间轴刻度与 tooltip 日期全部按 zh-CN 显示：年刻度「2026年」、月刻度「3月」、
  日刻度「3月26日」；**禁止出现「26 3月 '26」「Mar」这类英文 locale 格式**。
- 实现要点：lightweight-charts 的 timeScale.tickMarkFormatter 自定义 +
  localization.locale = 'zh-CN'；价格轴与数值统一 ¥（现有规范保留）。

F5 副图指标可切换
- 至少提供：MACD、RSI、Force Index、Elder-Ray、随机指标（Stochastic）五个，可切换或勾选。
- 多副图布局允许下拉/标签切换或纵向排列，保持画面与现有风格协调即可。

F6 买卖点与依据面板保留
- 三重滤网 BUY/SELL 箭头保留，可整体开关（默认开）。
- 点击箭头的依据面板保留：rule_id、source_quote、source_url、confidence、
  书内确认标注、止损价与 2% 仓位；字段语义与现有版本一致，不得删改。
- 溯源数据来自 docs/indicators.yaml 的 specs（book_* 字段 + source_url/source_quote），
  由前端打包内嵌一份精简 JSON（只含 rule_id 相关展示字段，不含全量 YAML）。

F7 查询体验
- 复权切换：前复权（默认）/ 不复权，二选一切换。
- 展示接口返回的全部数据；如实现范围快捷选择（近 1 年 / 全部）为加分项，非硬性。
- 连续查询做防抖；接口失败自动重试 1 次，仍失败则显示中文错误。
- 页面固定角落声明：「行情数据：腾讯公开行情接口（非实时），仅供研究参考」。

【已验证的技术事实 — 直接采用，不要重新调研、不要换数据源】
====================================================================

1. 行情源（2026-11-21 用 curl 实测）：
   - 腾讯 fqkline（首选，浏览器可直连）：
     https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sh600519,day,,,1000,qfq
     响应头含 access-control-allow-origin: *（fetch 跨域直接可用）。
     日线在 data.sh600519.qfqday（不复权请求去掉 qfq 时字段为 day）；
     周线 param=sh600519,week,,,300,qfq → data.sh600519.qfqweek。
     K 线元素为字符串数组：[日期, 开, 收, 高, 低, 成交量]。
     ⚠️ 实测请求 1000 根只返回 640 根：数据量以实际返回为准，做好自适应，不要假设固定根数。
   - 股票名称：https://qt.gtimg.cn/q=sh600519 返回 GBK 编码文本
     v_sh600519="1~贵州茅台~600519~1485.75~..."（~ 分隔，第 2 段名称、第 3 段代码）；
     浏览器端用 new TextDecoder('gbk') 解码。
   - 东财 push2his.eastmoney.com 连续请求会被限流（curl 52 Empty reply），
     **不要作为唯一数据源**；如做备用源必须带失败兜底。
   - 60 分钟线 /appstock/app/kline/mkline 实测返回 301：若需要分钟线，自行验证可用地址；
     **验证不通就在本阶段降级**——第 3 重触发改用「日线 T-1 高低点突破」，
     并在页面注明「日内触发为日线近似」。
2. lightweight-charts v4.2.3 本地文件已在发布目录
   （lightweight-charts.standalone.production.js）：新页面引用这一份本地文件，
   不要重新引用 unpkg CDN。
3. 指标公式与参数必须与 docs/indicators.yaml 一致：
   EMA13、MACD(12,26,9)、RSI(14)、Stochastic(13,3) 阈值 30/70、Force Index EMA2、
   第 1 重 = 周线 EMA13 斜率 + MACD 柱斜率双确认、
   第 2 重 = 日线 Elder-Ray / Stochastic / RSI 任一成立为 setup、
   第 3 重 = T-1 高低点 ± tick 突破（60m 可用则用 60m）。
   买卖点为提示性标注，页面保留「仅供研究与回测，不构成投资建议」。
