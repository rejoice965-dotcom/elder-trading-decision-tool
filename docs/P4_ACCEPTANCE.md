## 回放与已收盘数据

- `./scripts/run_all.sh 600519.SH 贵州茅台` 读取 Sina 缓存，计算展示指标，生成临时信号 CSV 并将同一份 CSV 传给 HTML 生成器。回放得到 120 条，买 56、卖 64，非空 `source_page` 为 0。
- `rg -n 'shift\s*\(\s*-' elder_indicators market_data strategy_adapters presentation` 无匹配。provider 按收盘时间标记 `is_closed`，周线聚合排除未收盘日线，信号入口过滤三个周期的未收盘记录。周线到日线向后匹配，分钟线到日线严格向后匹配，因此 15:00 的分钟 bar 不会看到同一时刻的日线。
- `test_future_data_perturbation_does_not_change_past_signals`、`test_incomplete_same_day_daily_bar_cannot_leak_into_intraday_signal`、`test_suspended_intraday_bar_cannot_emit_signal` 三项通过。该证据针对固定缓存与带收盘状态的输入。前复权历史会随新的公司行动变化，本次未验证历史时点可获得的复权因子。
- 本地 HTTP 加载了 CDN 图表并实际渲染。页面显示标题、K 线、EMA、四个副图和信号详情。截图见 [p4-browser.jpg](../examples/p4-browser.jpg)。
